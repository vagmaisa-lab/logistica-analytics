# Logística Analytics

Base de conhecimento profissional de **Logística**, **Analytics**, **SQL**, **Power BI** e **n8n**.

Este repositório organiza projetos, consultas, regras de negócio e documentações relacionadas à área de logística e dados, facilitando a reutilização de conhecimento e o uso com diferentes IAs.

---


### Objetivo
Centralizar e organizar:

- Estruturas e scripts de banco de dados
- Consultas SQL reutilizáveis
- Regras de negócio da logística
- Projetos de analytics e produtividade
- Automações com n8n
- Documentações técnicas e de negócio

A ideia é que qualquer pessoa (ou IA) consiga entender o contexto navegando pelos arquivos.

### Como contribuir / usar

1. Navegue pelas pastas de acordo com o tema
2. Consulte a documentação em `docs/`
3. Utilize os arquivos de `knowledge/` como referência rápida
4. Sempre documente novas regras de negócio em `docs/regras_negocio.md`
